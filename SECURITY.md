<a name="english"></a>
## English

### Supported Versions

We actively maintain and provide security updates for the latest versions of VisorLink:

| Version | Supported          |
| ------- | ------------------ |
| 4.x.x   | :white_check_mark: |
| < 4.0.0 | :x:                |

### Reporting a Vulnerability

We take the security and privacy of our users very seriously. If you discover a security vulnerability or security bug, please report it **privately**:

- **Do NOT** open a public issue on GitHub.
- Submit your finding via GitHub [Private Vulnerability Reporting](https://github.com/your-username/VisorLinkMobileAndroid/security/advisories/new) or send an email to the project maintainers.
- Include a detailed description of the vulnerability, reproduction steps or Proof-of-Concept, and the affected versions.

We will acknowledge your report within 48 hours and work on a fix as quickly as possible.

### Сообщение об уязвимостях

Если вы обнаружили потенциальную проблему безопасности или уязвимость:

- **НЕ публикуйте** информацию в открытых GitHub Issues.
- Используйте механизм [Private Vulnerability Reporting](https://github.com/your-username/VisorLinkMobileAndroid/security/advisories/new) на GitHub или свяжитесь с мейнтейнерами напрямую.
- Приложите подробное описание проблемы, шаги воспроизведения или PoC.

Мы ответим на ваше обращение в течение 48 часов и подготовим исправление.
